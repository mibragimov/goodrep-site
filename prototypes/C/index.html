One session, four screens

Every set, logged honestly.

  1. One tap a set

    Yesterday's 80 × 8 is already in the fields. Went heavier? Change the number, then tap Add set.

    Pick from more than 400 exercises on a body map, set targets like 3 × 8–10 and pair supersets.

    Sets, reps, volume and time, with a map of the muscles you trained. Share it as an image.

    A calendar marks each training day. Open one to see every set you did.
